# DASHBOARD_XBOX_GAME
Dashboard analítico desenvolvido no Excel para monitorar e analisar as vendas de assinaturas e passes de temporada do ecossistema Xbox Game Pass.

# Sobre o Projeto

O objetivo principal deste dashboard é fornecer uma visualização clara e centralizada das receitas geradas por diferentes tipos de assinaturas e conteúdos adicionais (Season Passes) dentro da plataforma Xbox.
